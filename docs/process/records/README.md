# Process Records

Archive of the **records produced by running the process** — the evidence trail an
appraiser checks against the ratings in `../02-process-assessment.md`.

| Record | Template | Frequency |
| --- | --- | --- |
| Measurement Report | `../templates/measurement-report.md` | Per increment / release |
| Closure note | `../templates/change-request.md` §8 | Per release |
| Appraisal snapshot | `../02-process-assessment.md` §2 | Per IDEAL cycle |

## Naming

```
YYYY-MM-DD-<type>-<short-name>.md
# e.g. 2026-09-20-measurement-cycle-1.md
```

## Rule

Records are **append-only** — never edit a filed record. Supersede it with a new
one and note the supersession. A record that can be rewritten is not evidence.
